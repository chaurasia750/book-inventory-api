## 1. In one minute
After this plan the Owner can download the ledger statement of a school or a vendor as an A4 PDF with the same filters as the screen: `GET /api/v1/schools/{id}/ledger/pdf?financialYear=2026-27`.

## 2. Touches / leaves out
Touches: `Application/Finance` (a PDF service that reads the statement through the existing statement use case, a model builder and one embedded A4 template with a repeating header and footer), the `ICompanyInvoiceIdentity`, `ISchoolDirectory`, `IVendorDirectory` capabilities for the header and the party, `Api/Controllers/Finance` (two endpoints), the message catalogue, the module template folder in the csproj. No schema change.
Leaves out: the Download button (finance#08), the links (finance#09), the outstanding lists.

## 3. Approach
The service asks the statement use case (R9) for the statement of the filter, so the PDF and the screen can never disagree, then fills one template through the platform template port and renders it with the platform PDF renderer like the invoice PDF. The company header and the page footer repeat on every page; the filter is described in words from the query.
