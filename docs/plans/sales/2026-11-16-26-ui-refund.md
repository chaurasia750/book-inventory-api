## 1. In one minute
After this plan the Owner opens **Orders > Refunds**, sees the refunds, records one (school, amount, mode, date, optional credit note, remark), reads it beside the list, prints or downloads its **refund slip** and can cancel it. The school's profile and the credit note show the refunds that belong to them.

## 2. Touches / leaves out
Repository `book-inventory-ui` (build: `npx nx build member`, lint: `npx eslint` on the touched folders): a `refunds` page folder under `apps/member/src/app/pages/`, `libs/api-services` (a refund service), `libs/shared-models`, the menu (Owner only), the credit note detail and the school profile (a "Refunds" block), `assets/i18n/en.json`.
Leaves out: refunds to customers or vendors, the credit note PDF buttons.

## 3. Approach
The list-and-detail panel as the other records (X to close, id in the URL). The school is chosen with the shared searchable school select and its credit balance is shown beside it; the amount is checked against it on the screen as well (the API checks again and its message is shown). The shared date picker, a dropdown for the mode, the reference field only for UPI and Bank. Print and Download PDF buttons call the slip endpoint like the counter bill.
