## 1. In one minute
After this plan the Owner and Staff have a **Counters** menu: the list of counters with search and filters, the Owner adds, edits, closes and opens a counter in the side panel, and a counter row has "Open billing" (the billing screen arrives with sales#18). Open `/<company>/counters`.

## 2. Touches / leaves out
Touches: `libs/shared-models` (counter model), `libs/api-services` (`CounterService`), `apps/member` (`pages/counters`: list, detail panel, form; routes `counters`, `counters/new`, `counters/:id`, `counters/:id/edit`; the menu entry for Owner and Staff), `assets/i18n/en.json`.
Leaves out: the billing screen, the bills list and the summary (their own UI plans).

## 3. Approach
It follows the vendor and school screens (platform U10: list beside a panel, X to close, the id in the address). The form has the school (only schools that sell at the counter), the session choice from the school's session choice, the dates and the name (with a suggested `<school> Counter <session>`); Staff see the list and the panel but no Add, Edit, Close or Open. Each state shows loading, empty, error with retry and success; all texts from the catalogue.

## 6. Not verified
Every row of section 5 was checked against the running API in headless Chrome (real login, company `abc-book-center`).

Done and observed:
- The Counters screen lists the company's counters (name, school + code, session, start, end, status, Open billing); the status filter narrows the list ("No counters match." when empty).
- The New counter panel offers the counter-selling school (`Cus Check School 22dab7`, `BOTH`); the session choice follows the school (`2025-26`, `2026-27`, `2027-28`) and the name is suggested (`Cus Check School 22dab7 Counter 2026-27`). An end date before the start shows "The end date cannot be before the start date." and the form stays.
- Creating a counter shows it Active in the panel; Close counter -> Closed; Open counter -> Active; Open billing opens `/<company>/counters/<id>/bill`.
- Staff (`abcbookcenter.salescheck`) see the list without "New counter" and the panel with only "Open billing" (no Edit / Close-Open).

**Not verified:** "a school that does not sell at the counter is not offered" - the company has a single school (`BOTH`), so no order-only school was available to see it left out. `npx nx run-many -t build --projects=member` -> success; `npx nx run member:lint` -> only the three known findings (`member-layout.ts`, `account-pages.ts`, `change-password.ts`).
