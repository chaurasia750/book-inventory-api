# BookInventory BuildingBlocks

Shared building blocks for .NET 10 Web APIs on PostgreSQL. Reference only the layers a service needs.

| Package | Layer | Depends on |
|---|---|---|
| `BookInventory.BuildingBlocks.Domain` | Entities, audit bases, domain events, paging models | nothing |
| `BookInventory.BuildingBlocks.Application` | Event dispatcher, `[AutoRegister]` DI scanning | Domain |
| `BookInventory.BuildingBlocks.Persistence` | EF Core + Npgsql, snake_case, soft delete, audit, repository, unit of work | Domain, Application |
| `BookInventory.BuildingBlocks.Configuration` | Controller base, filters, JWT, CORS, versioning, OpenAPI, health | Domain, Persistence |
| `BookInventory.BuildingBlocks.Logger` | Serilog (console + rolling JSON file) | - |

Dependencies only point downwards: `Configuration -> Persistence -> Application -> Domain`.

## Quick start

```csharp
// Program.cs
var builder = WebApplication.CreateBuilder(args);

builder.Host.AddLogger();
builder.Services.AddApiBuildingBlocks(builder.Configuration);
builder.Services.AddPostgresPersistence<AppDbContext>(builder.Configuration.GetConnectionString("Default")!);
builder.Services.AddApplicationBuildingBlocks(typeof(Program).Assembly);          // event handlers
builder.Services.AddAutoRegisteredServices(typeof(Program).Assembly);              // [AutoRegister] classes

var app = builder.Build();
app.UseRequestLogging();
app.UseApiBuildingBlocks(builder.Configuration);
app.MapApiBuildingBlocks();
app.Run();
```

```csharp
public class AppDbContext(DbContextOptions<AppDbContext> options, ICurrentUser currentUser, IDomainEventDispatcher dispatcher)
    : BuildingBlocksDbContext(options, currentUser, dispatcher)
{
    public DbSet<UserProfile> UserProfiles => Set<UserProfile>();

    protected override void ConfigureModel(ModelBuilder modelBuilder) =>       // not OnModelCreating
        modelBuilder.ApplyConfigurationsFromAssembly(typeof(AppDbContext).Assembly);
}

// Aggregate root: owns its children, enforces invariants, raises events, has a concurrency token.
public class Wallet : AggregateRoot
{
    private readonly List<LedgerEntry> _entries = [];
    public decimal Balance { get; private set; }
    public IReadOnlyList<LedgerEntry> Entries => _entries;

    public void Credit(decimal amount)
    {
        if (amount <= 0) throw new ValidationFailureException("finance.wallet.amount_not_positive");
        Balance += amount;
        _entries.Add(new LedgerEntry { Amount = amount });
        AddDomainEvent(new MoneyCredited(Id, amount));
    }
}

public class LedgerEntry : TransactionDomainBase { public decimal Amount { get; set; } }   // child entity, no repository
```

Only aggregate roots get a repository (`IRepository<Wallet>`); `IRepository<LedgerEntry>` does not compile.

`UserProfile.FirstName` is stored as `user_profiles.first_name`; keys, indexes and foreign keys are snake_case too
(`pk_user_profiles`, `ix_wallets_user_profile_id`, `fk_wallets_user_profiles_user_profile_id`).

## Behaviour to know about

- **Soft delete.** `repo.Remove(x)` sets `is_deleted = true`; every read hides deleted rows through a named EF query
  filter (`Table.IgnoreQueryFilters()` to see them). For a hard delete use `repo.Table.IgnoreQueryFilters().Where(..).ExecuteDeleteAsync()`.
- **Keys.** Every entity gets a UUID v7 `Guid` id in its constructor (never generated by the database): ids exist before
  saving and sort by creation time. Use `AddAsync` for new aggregates and `Update` only for existing ones.
- **Naming.** Tables are singular snake_case in the module schema (`iam.app_user`) through `ModuleEntityConfiguration<T>`;
  keys, foreign keys and indexes are named `pk_<table>`, `fk_<table>_<principal>_<cols>`, `ix_<table>_<cols>`. Enums are stored
  as UPPER_SNAKE text with a `CHECK` constraint.
- **Audit.** `created_at/created_by` and `updated_at/updated_by` are stamped in UTC from `ICurrentUser` (JWT claims in the
  API host; `Guid.Empty` in background jobs).
- **Transactions.** `TransactionFilter` opens one transaction per write request (POST/PUT/PATCH/DELETE), commits on
  success, rolls back on exception or 4xx/5xx. GET requests do not open one. Repositories never call `SaveChanges`;
  the commit does. Outside HTTP: `await uow.StartTransactionAsync(); ...; await uow.CommitAsync();`.
- **Failures that must leave a trace.** An action marked `[PersistOnFailure]` (for example a failed login) commits its work
  even though it returns 4xx; an exception still rolls back.
- **Errors and messages.** Business exceptions carry a message code; the text comes from the module's message catalogue
  (`AddMessages`) and the problem details include `code`. Routes are short (`[Route("auth")]`) and get `api/v1/` by convention.
- **Configuration** sections use `AddValidatedOptions<T>`; invalid values stop startup.
- **Aggregates.** `AggregateRoot.RowVersion` is an optimistic concurrency token mapped to PostgreSQL `xmin` (no extra
  column); concurrent edits of the same aggregate surface as `DbUpdateConcurrencyException` -> 409.
- **Domain events** raised by the root (`AddDomainEvent` is protected) are dispatched after `SaveChangesAsync`, inside the
  transaction. A failing handler rolls the request back. The synchronous `SaveChanges` throws if events are pending.
- **Foreign keys** default to `ON DELETE RESTRICT` (EF's default is CASCADE). Configure explicitly to change.
- **No retry strategy** is enabled, because user-initiated transactions are incompatible with it.
- **Sorting** by client-supplied column names (`OrderBy("name desc")`) is validated against the entity.
- **Errors** are RFC 9457 problem details (`GlobalExceptionHandler`); unique/foreign-key violations become 409.
  Exception details are only returned in Development. There is no response envelope: return plain results.
- **JWT.** The signing key must be at least 32 bytes (startup fails otherwise); clock skew is 1 minute (configurable via
  `JwtSetting:ClockSkew`); a missing or malformed claim reads as 0 / null instead of throwing.
- **CORS.** Set `Cors:AllowedOrigins` to allow specific origins with credentials. With none configured any origin is
  allowed, but without credentials.
- **Paging** is 1-based; page size is clamped to 200.
